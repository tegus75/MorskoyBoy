# ⚓ Морской бой

Классическая игра для Android. Полностью офлайн, без рекламы и интернета.

### 🎮 Особенности
- Поле 10×10 по классическим правилам
- 3 уровня сложности противника (от Юнги до Адмирала)
- Красивая анимация, звук и вибрация
- Сохранение прогресса и званий

### 📥 Как установить
1. Перейди в раздел **[Releases](../../releases)** (ссылка справа или вверху).
2. Скачай файл `MorskoyBoy.apk`.
3. Открой его на телефоне и разреши установку.
4. Играй!

> Минимальная версия Android: 7.0
